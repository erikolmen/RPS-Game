About Me

This app was built for the Intro to Python web app exercise, using Flask and Bootstrap.

  • Rock, Paper, Scissors
    Pick a move from a dropdown, play against the computer, and keep score.
  • Stocks Dashboard
    Daily stock prices from the AlphaVantage API, shown as summary stats, a Plotly chart, and a table.
  • Tested and Deployed
    Automated tests run on GitHub Actions, and the app is hosted on Render.
